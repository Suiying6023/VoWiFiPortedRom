# VOXI 保号与项目维护

核实日期：2026-09-13。项目按保号用途维护；语音通话仍失败，不属于本版本的可用承诺。

## 账户规则

取消首月套餐后，号码仍属于 VOXI，按标准费率从充值余额扣款。
这不是自动迁移为 Vodafone 的另一种 PAYG 产品。

[VOXI 正式条款 v2.17（2025-10-20）](https://assets.ctfassets.net/49k3mgcbymb9/5w9efRVyncm0pfFUgbLDZE/742bf8f7f22d71c0dd54d693e6f614c1/VOXI_PDF_DOC_-_v17_-_voxi_terms_and_conditions.pdf)
第 1(a)、3(b)、5(b)(ii)、5(c) 条明确规定：

- 购买套餐、充值、收费外发活动都算使用服务。
- 连续 180 天没有有效活动可暂停服务；再过 90 天仍无活动可断线并失去余额。
- 免费的 `191` 不算，单纯接收短信、保持 IMS 在线也不能代替有效活动。

执行前可从 [VOXI 条款入口](https://www.voxi.co.uk/terms-conditions) 核对是否更新。
帮助页的“6～9 个月断线”是概述，具体活动定义以上述正式条款为依据。

## 推荐做法

按 **150 天**设置个人日程，留出一个月处理短信失败、支付失败或忘记操作。
上次有效活动的日期，以账户记录为准；本次维护没有访问账户账单，也没有触发付费操作。

1. 查看上次有效活动日期和余额。
2. 向自己控制的正确号码发送一条普通收费短信，并核对实际扣费；历史实测为 £0.24/条，未来费率以实际账户为准。
3. 若短信通道不可用，可在 VOXI 网页账户充值。充值本身即符合条款，不依赖手机 IMS 注册成功。
4. 保存日期、活动类型及成功凭据，以下一次“活动日期 + 150 天”为操作日。

| 活动日期 | 类型（短信 / 充值 / 套餐） | 扣费或充值成功凭据 | 下次操作日 |
|---|---|---|---|
| 以账户核实结果填写 | | | 日期 + 150 天 |

`RP-ACK` 表示短信信令被接受，不证明对方收到，也不等于本次扣费已经入账。
项目历史有真实 £0.24 扣费及收短信记录；本次只复核本地链路，没有重发收费短信。

## 工程的归档边界

当前保留三组件结构和已验证二进制，适合冻结功能开发，按需维护。
无需为保号增加自动拨号、自动付费短信、代理桥接或重新研究 modem 路线。
上游回馈可以独立进行，不影响当前号码维护。

v7 修复了监控的双卡判定、旧日志更新时间、重复实例问题，并补全配置键验证。
载荷与真机一致：Iwlan v13、phh v43、MinQns v1。
声称“通话全面可用”的历史实验结论不能作为当前可用性承诺。

## 恢复

保留 Release ZIP、校验清单，以及可重新打包的源码。
新系统上通过 KernelSU 安装并重启，再运行状态脚本检查隧道、注册与监听。
更换 ROM/API 后，二进制可能需要重新适配。

开发工作区里的签名密钥、ROM 框架文件、源码、共享 JDK/jadx 和刷机备份属于重新编译与恢复依赖。
预编译模块只需约 1.5 MB；不要为缩减部署包而合并 UID 或删除这些本地恢复依赖。
